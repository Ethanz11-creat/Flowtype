# macOS 原生客户端体验与服务联调设计

日期：2026-11-03

状态：本设计于 2026-11-03 获用户确认；原生实现、Tasks 1–11 及集中修复已完成独立审查。当前候选的 code／artifact 证据见[验收记录](../validation/2026-11-03-native-client-acceptance.md)。41 项真机验收和远端 CI 仍 Pending，尚未完成发布验收。

## 1. 目标与确认范围

在现有 SwiftUI 客户端和 M1–M5 服务之上，完成页面逻辑、真实状态联动与视觉细化。面向使用本地或自备云端服务进行日常语音输入的 macOS 用户，让其能找到配置、完成首次听写、辨认结果并从失败中恢复。

用户已确认：

- 原生 macOS 优先；参考 Typeless 的信息组织与恢复思想，保留 FlowType 自己的视觉。
- 概览保留现有全部模块，沿原版布局细化。热力图和小时图分别占一整行，允许纵向滚动。
- 主导航保持「概览／历史／词典／风格／设置」，设置分为「语音识别／文本整理／通用／权限与隐私」。
- 识别模式控件靠左、按内容定宽，约 276×40pt；配置按模式折叠而不是删除或完全隐藏。
- “仅本地”只约束语音识别；开启云端整理时明确文字仍会发送。区分已选模型／服务与一次听写实际使用的引擎。

[归档交互原型](../prototypes/2026-11-03-native-client.html)包含已确认概览和设置设计。里面的统计、模型、服务及权限状态全部是合成示例；操作不联网、不录音、不下载、不保存配置。浏览器控件仅用于沟通原生页面设计，不是产品网页。

首次使用、配置提交、试说生命周期、历史／词典／风格页细化与验收约定已随本书面设计获确认；设计确认不代表实现或验收已经完成。

## 2. 实现边界与依据

复用 ConfigurationStore、ReadinessMonitor、QwenModelState、CloudASRConnectionCheck、SessionController、OnboardingPipeline、HistoryStore、DictionaryStore、StylePackStore 和 StatsEngine。页面通过 Swift 状态与动作连接现有服务，不增设 localhost HTTP 后端，不改 ASR 协议与模型架构支持范围。

本轮不新增云端厂商 SDK、通用 Hugging Face 任意架构推理、账户订阅、实时模型训练或新的数据库统计口径。已有 M1–M5 路由快照、模型 lease、取消归属、单次交付、剪贴板保护、恢复资源及发布门禁继续有效。

## 3. 视觉、尺寸与共享组件

延续已确认原版方向：不透明中性背景、克制紫色重点、成就用少量暖色。侧栏、内容、控件有清晰明暗关系。去掉英文口号、背景纹样、重复状态条及堆叠装饰卡片。

- 保持现有最小窗口 1040×700pt，初始窗口 1120×760pt。侧栏 176pt。
- 概览和设置有效内容最大宽度 844pt，左右内边距各 28pt，总占位最大 900pt；更宽窗口增加留白。
- 标题约 18pt，正文／控件 12–13pt，说明 11–12pt，图轴可用 10–11pt，统计数字 28–31pt。沿用原生排版习惯，不通过缩小字号或整体缩放塞入首屏。
- 主内容区域纵向滚动，侧栏保持固定；短窗口不压缩图表、卡片或弹窗字体。
- 复用主题、分组容器、设置行、状态文字、按钮和表单组件。按内容定宽的选择器与填满容器的列表区别处理，不把全部控件都设成等比分栏。
- 支持浅色、深色、随系统；控件有可见焦点、可读禁用态，颜色之外同时用文字表示状态。动画遵循减少动态效果设置。

## 4. 导航与定位

保留五个主入口，不新增“识别配置”主导航。设置内部用四个横向分组，避免第二层侧栏挤占宽度。

SettingsNavigation 增加可定位设置分组的目的地与请求身份，继续兼容现有按 AppTab 打开的调用。每次外部请求均可被已打开窗口消费；重复定位相同分组也能滚动到对应设置项。

| 来源 | 目的地 |
| --- | --- |
| 无引擎、密钥、URL、模型配置问题 | 设置 → 语音识别；有服务 UUID 时定位对应行 |
| 麦克风／辅助功能权限提示 | 设置 → 权限与隐私 → 对应权限 |
| 模型下载／加载问题 | 设置 → 语音识别 → 本地模型 |
| 管理文本整理 | 设置 → 文本整理 |
| 管理生效风格 | 风格 → 对应风格包 |
| 查看历史 | 历史；有已持久化记录 ID 时选中该记录，否则保持普通列表 |

页面切换不重建正在录音的业务控制器，不重新注册热键、不请求权限、不自动下载模型。存在未提交的服务草稿时，关闭或离开编辑框需明确保留编辑或放弃草稿。

## 5. 概览

保持进度环、节省时间、口述字数、总口述时间、平均速度；保留活跃天数／当前连续／最长连续、七个里程碑、年度热力图、24 小时分布和趣味页脚。

- 进度环为已启用词条数／全部词条数，零词条为 0%。不是模型学习进度。显示具体比例，提供词典入口。
- StatsEngine、StatsConfig 是统计口径来源。手工输入基准保持 45 字／分钟；字数沿用 SessionRecord 的原始识别字数，录音时长优先 recordingMs、兼容历史 durationMs；不改成整理后字数。
- 全部／30 天／7 天更新汇总、成就主值、小时图和页脚。热力图始终显示最近 365 天；本月活跃及最佳月份沿用当前全量统计口径，不偷偷改公式。
- 热力图独占整行，保留星期对齐、月份、五级图例和日期／字数悬停详情。在最小窗口布局中，参考宽度约 779pt、格子约 12pt。
- 小时图独占整行，绘图区约 112pt 高，24 个真实桶；清楚显示小时、听写次数和高峰。零次数不画虚假正值柱。
- 七个里程碑保持 3／7／14／30／60／100／365 天；继续复用当前进度和颜色规则。
- 无记录时显示首次听写指引，不制造热图活跃点。低数据时如实保留稀疏分布。页脚保留电影／咖啡的现有阈值。
- 前台恢复与会话持久化后更新数据；不把图表拉小以让首屏容纳全部模块。

## 6. 设置：语音识别

### 6.1 模式选择

靠左展示三个自然宽度选项，整体约 276×40pt，下方解释当前模式。键盘可以选择，显示明确的当前选项。

| 模式 | 实际语义 | 默认展开 |
| --- | --- | --- |
| 仅本地 | 仅使用可用本地 ASR；不向云端 ASR 发送识别录音 | 本地模型 |
| 自动（推荐） | 沿用现有健康决策，默认云端优先；网络慢、连续失败等可让本地优先；只尝试可用候选 | 本地模型、云端服务 |
| 仅云端 | 只使用配置的云端 ASR，不切到本地 ASR | 云端服务 |

另一配置区以“此模式不使用”折叠，仍可展开准备模型或编辑服务。展开不切换模式；切换模式不清除配置、不自动下载，也不改变当前录音捕获的路由快照。

“仅本地”不是整个应用的离线总开关：polishOnStop 开启且使用云端整理时，显示“已开启云端文本整理，转写文字仍会发送给整理服务”，并提供进入文本整理的入口。不擅自关闭整理或改变已有偏好。

### 6.2 本地模型

保留 0.6B／1.7B 下载与硬件自动推荐，兼容 Qwen3-ASR MLX、Whisper Core ML 导入，不声称任意 Hugging Face ASR 模型都能运行。

列表区别“已选模型”“已加载可用模型”“正在准备的目标”，来源以现有 activeLease、模型操作状态和 ModelRecoveryPresentation 为准。下载完成不等于加载成功。内存、磁盘和文件完整性检查继续由现有服务执行。

下载展示大小、进度、取消和错误恢复；切换加载串行归属于 QwenModelState。自动推荐 1.7B 失败时按既有规则尝试 0.6B 并显示降级，手动选择不静默改写。加载失败时保留先前可用 lease 与已保存选择的既有事务行为。

导入走文件夹选择 → 检查格式／完整性／硬件 → 预览 → 明确“加载并使用”；检查本身不提交模型选择。保留重新定位、移除记录和失败原因；移除导入记录不删除用户下载目录。

### 6.3 云端服务

列表保留多个服务档案与唯一活动选择；简洁显示名称、模型、已选状态与验证状态。编辑弹窗放厂商、URL、密钥、模型；模型和协议高级选项不挤占列表首屏。

新增档案可采用厂商预设；编辑已有档案时不因切换厂商直接覆盖已有 URL、模型和密钥。需要替换时提供显式“使用厂商默认值”动作，并保留取消返回草稿的能力。自定义服务的模型 ID 作为必填主字段，不藏进高级配置。

编辑使用草稿。取消不改活动配置；保存前校验，提交按 UUID 合并到最新配置，避免旧数组下标或整份旧配置覆盖其他页面的变更。已删除的档案不能被迟到的草稿或测试重新创建。

密钥留空默认保留既有值；删除密钥必须有明确动作。沿用当前本地配置存储，不声称已经迁移到系统 Keychain。列表、状态、日志和诊断不回显密钥。

| 状态／动作 | 展示合同 |
| --- | --- |
| 尚未验证 | 配置存在，不等于请求已成功 |
| 检查配置 | 本地校验，不联网；通过后显示“配置有效；尚未连接” |
| HTTP 测试识别 | 明确告知向当前 URL 发送密钥和 0.5 秒合成静音音频，可能计费；用户执行后才发送 |
| 实时 WSS | 不显示 HTTP 测试按钮；说明连接与识别在真实录音时验证 |
| 测试成功／失败 | 绑定该档案与该修订，不跨服务或编辑后的配置复用结论 |

沿用 CloudASRConnectionCheck 的 UUID／revision／in-flight 归属。草稿测试拥有独立修订标识，不借测试隐式保存或启用草稿；有改动后旧结论失效。测试过程中可取消编辑，迟到结果不覆盖新页面、新档案或新配置。

语言和麦克风保持紧凑设置行；拔掉所选设备时显示不可用提示并保留选择，不静默宣称仍在使用该设备。

## 7. 设置：文本整理、通用、权限与隐私

### 文本整理

提供停止后自动整理开关、独立 LLM 服务列表、管理风格入口与高级默认提示词。ASR 与整理的模型、URL、密钥和活动服务互不覆盖；“仅本地识别”不隐式禁用整理服务。

提示词来源与代码一致：StylePackStore.activePack 优先活动且启用的风格，其次内置 structured；LLMService.composeSystemPrompt 在没有返回风格包时才使用 Configuration.systemPrompt。显示当前生效风格来源，解释修改默认提示词不会覆盖该风格，并提供编辑生效风格的入口。不在本轮改写提示词优先级。

### 通用

集中外观、触发键、交互方式、提示音、录音时长和文字交付方式。控件保留当前枚举完整选择，触发键提示与实际配置同步，不写死双击 Command。

配置保存与副作用分离：只有触发键／交互模式等相关字段变化才重建所需热键绑定；修改外观、隐私或服务草稿不重载热键。保持现有保存防抖与退出 flush；保存反馈安静显示，不每按一个字符弹绿色浮层。

### 权限与隐私

| 权限情况 | 页面与能力 |
| --- | --- |
| 麦克风未请求 | 用户明确开始录音时请求；仅查看页面不触发弹窗 |
| 麦克风被拒绝 | 阻止录音，定位系统麦克风设置；保留已有配置 |
| 辅助功能未授权 | 明确菜单可以开始听写、结果写入剪贴板；全局热键和自动落字不可用 |
| Apple Speech 未授权 | 只解释 Apple 基础识别依赖，不要求使用本地／云端 ASR 的用户一律授权 |

统一使用 ReadinessMonitor 的状态及重新检测入口；从系统设置返回会更新，不再复制另一套永久轮询与布尔状态。阻塞和降级分别表示；已选服务／配置通过／可开始尝试／实际识别成功不混为一谈。

保留转写文本保存、云端上下文总开关、整理上下文子开关及诊断。仅本地下禁用上下文发送相关控件；禁用不清除原选择。子开关依赖总开关。Paraformer 实时识别不发送上下文。关闭文本保存只影响后续文本，已有文本须由历史清除动作处理。

## 8. 首次使用与试说（本次书面方案）

首次使用采用简短、可返回和可稍后完成的流程：了解用途 → 选择识别方式并准备可用引擎 → 按需授权 → 试说。复用设置中的配置组件和状态，避免 onboarding 再维护一份不一致配置。

本地准备须展示资源需求；云端使用用户显式保存的配置。不因首次打开页面或“完成设置”而偷偷启动一个未确认的模型下载。辅助功能可以稍后授权；麦克风拒绝不锁死配置页面或删除设置。

“试说一句”置于设置页顶部，并在首次使用中复用同一试说内容。提供按钮开始／停止／取消，不强依赖全局修饰键；触发键说明使用真实配置。无可用引擎时定位语音识别，不让空白结果区假装在录音。

识别和整理继续走现有阶段，结果经 DemoInjectionStage 进入试说区，绝不调用真实应用注入。正式实现需为试说注入明确的临时 effects／observers：不写正式历史和统计、不学习词条、不覆盖真实最近交付，也不自动复制结果。当前 demo 的默认 live effects 不能仅因替换了 InjectionStage 就被认定已经隔离。

同一时刻只允许普通听写或试说占有录音资源，按钮状态体现当前占用。关闭试说、切页或重新开始时取消旧会话；迟到的 ASR／整理回调不能刷新新结果。只在结果可用时显示显式复制按钮。真实试说进入云端时沿用配置及音频／文本发送说明。

## 9. 历史、词典、风格（本次书面方案）

### 历史

保留列表＋详情、搜索、原文／整理筛选、导出与复制。缩短常驻工具栏，将清空文本和重置全部统计放到明确菜单，避免两个相似的危险图标占主操作位。

详情先展示最终文本和复制操作，原始识别在不同时可展开；显示真实时间、模式及可用的引擎／耗时信息。读取失败应显示重试提示，不能伪装成没有记录；存储层需提供可观察的错误状态供页面消费。交付结果严格映射已有 DeliveryOutcome：

| 持久化值 | 允许的用户文案 |
| --- | --- |
| typedDispatched | 已发送键入事件 |
| pasteDispatched | 已发送粘贴事件 |
| clipboard | 结果已写入剪贴板 |
| uncertain | 无法确认是否输入；可复制结果 |
| cancelled | 已取消（仅对确实已有该值的记录） |
| nil／历史缺失字段 | 无交付状态记录 |

这些字段均不能推断目标应用已确认落字。已清除或未保存文本时禁用相应复制／单条文本导出动作，解释统计仍保留。批量 CSV 导出仍可包含这些记录的元数据，文本列留空；不恢复已删除文本。不从空文本反推精确的隐私关闭或清除时间。

单条删除沿用删除记录及相应统计更新；清空文本保留统计；重置全部统计保留既有两次确认。历史没有持久化可重试音频，不提供任意记录“重试原录音”按钮。

### 词典

保留添加、备注、自动发现来源、命中次数、启用／禁用与删除。使用可扫描的紧凑条目行，将启用操作从右键菜单提升为可见控件；搜索只过滤展示，不改变统计或词条。

删除与禁用有不同语义；输入空白不能添加。沿用现有 DictionaryStore 的规范化和数据写入，不新增“模型学习完成”“保证识别正确”等承诺。变化同步反映到概览词典启用比例。

### 风格

保留内置／导入／自定义风格、活动选择、编辑和 JSON 导入导出。列表先显示名称、用途、来源和生效状态；提示词编辑留在详情，不在每张卡片常驻大段等宽文本。

若展示输入／输出例子，必须标为说明性示例，不伪装成当前模型实际生成。实际运行预览如需云端请求，使用明确的试说／测试操作，不能仅切换风格就发请求。本轮不增加新的自动预览服务。

内置风格不可删除；删掉活动自定义风格时沿用回退到内置 structured 的规则，并立即更新生效提示。导入失败保留当前风格与编辑草稿。

## 10. 会话与失败恢复

主页面、菜单、浮动胶囊和恢复卡使用现有会话状态／Readiness 数据，不在每个页面独立推断“录音成功”或“输入成功”。选择设置与一次会话实际引擎分别展示；后者只取捕获路由、active lease 及最终 usedProviderID 等真实结果。

- 下载失败继续展示模型目标、可用模型与既有重试／换源／导入／0.6B 恢复动作。
- ASR 暂时失败且控制器仍拥有原音频、未开始交付时，才展示现有重试识别动作。
- 配置错误定位对应服务，不把所有错误统一变成“再试一次”。
- 整理失败沿用现有降级原文语义，历史模式不标成整理成功。
- 无法安全交付时保留结果并提供复制；已经发送但结果不明时禁止重复发送，保留查看历史等现有动作。
- 取消不会产生新的成功提示、词典学习、历史或复制；遵循当前对于已经发生交付的不确定终态合同。
- 用户开始新录音、关闭旧卡或切换会话后，旧卡操作继续按 cardID／sessionID／generation 检查；只展示控制器返回的可用动作。

不改变 RecoveryPolicy、20 秒停止后预算或 M3/M4 交付边界来迁就页面样式。

## 11. 组件与数据职责

| 单元 | 负责 | 不负责 |
| --- | --- | --- |
| Theme／基础视图 | 主题、设置行、状态、按钮、焦点、布局 | 引擎选择和联网 |
| MainWindow／SettingsNavigation | 页签、设置分组、定位请求 | 生命周期控制 |
| 设置分组与草稿动作 | 表单展示、校验、显式提交和字段副作用 | 自己发 ASR、拼协议请求 |
| Readiness 展示适配 | 将现有 snapshot／level 映射到统一状态与入口 | 发明另一套权限判定 |
| 模型／服务列表 | 调用现有协调器，展示操作和归属状态 | 自己持有第二套模型加载任务 |
| TrialSessionPresenter | 试说专用控制器、资源占用、临时结果与取消 | 普通听写的注入、学习或持久化 |
| 历史／词典／风格页面 | 调用各 Store，展示真实数据 | 修改统计公式、推断成功 |

配置继续由 ConfigurationStore 持有，统计由 SQLite 记录及现有 DailyStats 链路汇总。多个入口共享同一真实状态；视图只持有选择项、搜索词、草稿、展开和滚动等局部状态。

设置按分组拆分，避免把四页、弹窗、任务和副作用塞回 SettingsView 的单个大 body。保留现有公开入口的兼容调用；不新增另一套“前端后端同步”存储。

## 12. 验收与剩余主线

[实施计划](../plans/2026-11-03-native-client-experience.md)已按视觉与导航 → 设置与状态联调 → 试说及首次使用 → 历史／词典／风格 → 回归与真机验收执行。源代码和独立审查已完成；真机与远端 CI 的未执行项继续作为剩余主线。

自动验收优先使用独立 RuntimeEnvironment、合成记录、假配置／权限／网络／录音／剪贴板 effects，重点验证用户可见合同：

1. 外部定位能切换已打开窗口；重复请求、草稿取消、分组切换不触发录音／下载／热键重载。
2. 三种模式、折叠编辑、上下文禁用和本地＋云端整理文案一致；切换不丢配置。
3. 服务草稿取消不落盘，UUID／修订正确；旧测试结果不覆盖新配置；不把本地校验说成识别成功。
4. 只有相关设置触发热键副作用；不把“保存配置”与“验证云端”混成同一动作。
5. 权限拒绝／恢复、多个 blocker 和可降级能力展示正确，旧设置文案被替换。
6. 试说不产生正式注入、历史、统计、学习和自动复制；占用互斥、取消与迟到回调正确。
7. 历史交付映射、无文本动作、清空与重置语义正确；词典、风格变化能反映真实生效来源。
8. 概览沿用公式、365 天热图、时间范围和零值处理；更新不依赖重启窗口。

布局人工检查覆盖 1040×700、1120×760、宽窗口、浅／深／随系统、长 URL／模型名／词条／中英混合、键盘与减少动态效果。逐页检查默认／空／加载／错误／降级状态；不能只凭静态浏览器截图断言原生实现通过。

用户此前要求补入主线的真机项继续保留：真实云端弱网／断网及无效密钥、跨应用中文／英文／多行／emoji 落字、多格式剪贴板与并发复制、各阶段取消及迟到结果、拔麦／蓝牙断开后重新录音恢复。沿用 M5 的候选身份和逐项证据，不把旧二进制观察转记为新版本通过。

发布前按 M5 执行当前变更对应的 code／artifact／manual 门禁；人工与远端 CI 没完成时明确保留 Pending。本轮已交付原生实现与仓库内候选；源码、代码／产物门禁、原生离屏观察及其限制见[验收记录](../validation/2026-11-03-native-client-acceptance.md)。真机覆盖与发布验收继续以实际匹配的逐项证据为准。
