- [x] ⭐ **密码框/安全输入**：`IsSecureEventInputEnabled` → 剪贴板+提示音（不试注入、避免静默丢字）

## 二、待真机验证（代码已绿，效果未实测）⏳

### 键盘注入 —— 焦点导向决策（重做 spec 2026-06-03）
> 判定看「结束那一刻焦点是不是可编辑文本框」，不再看「切没切 app」。每次都打日志 `signals=secure=.. focus=.. → inject/clipboard`，照着核对走了哪条路。
- [ ] **原生 App 输入框**（备忘录/邮件）→ 直接注入
- [ ] **浏览器网页输入框**（Chrome + Safari 的 input/textarea）→ 直接注入
- [ ] **终端**（Terminal / iTerm2 / Ghostty 跑 Claude Code/Codex）→ 直接注入（AX 失明也照打 = focus=blindOrUnknown）
- [ ] **Cursor / VS Code** 编辑区 → 直接注入
- [ ] **微信** 聊天框 → 直接注入（不再误进剪贴板）
- [ ] **跨 App 注入**：口述中切到「另一个 app 的输入框」再结束 → 注入到**那里**
- [ ] **点状态栏/菜单结束** → 剪贴板 + 提示音（应为 focus=nonTextControl）
- [ ] **点桌面（无输入框）结束** → 剪贴板 + 提示音
- [ ] **密码框 / 安全输入** → 剪贴板 + 提示音、且**不卡死**（secure=true）
- [ ] **多行 Shift+Enter** 仍正常、不在终端误提交
- [ ] **风险点（spec §8）**：若「点状态栏」仍被注入（AX 把焦点报成原输入框）→ 告诉我，调 `nonTextControlRoles` / 加菜单检测

### Frost UI —— 明暗自适应磨砂（重做 spec 2026-06-03）
> 从状态栏图标打开主窗口；在「系统设置→外观」切 浅色/深色 各看一遍。
- [ ] **明暗自适应**：深色 = 深色磨砂、浅色 = 浅色磨砂，跟随系统自动切换
- [ ] **通透磨砂**：桌面光色透进来（通透）但卡片上文字清晰可读
- [ ] **侧栏 vs 内容区一致性（风险点 spec §6）**：侧栏与右侧内容区是否同一套磨砂质感？若侧栏发闷/不透/质感不同 → 告诉我，我在侧栏后面显式放 FrostMaterial
- [ ] **单一强调色**：降饱和紫只出现在 选中侧栏行 / 主按钮 / 录音点；窗口里**没有**紫蓝渐变了
- [ ] **颗粒**：有极淡颗粒、不刺眼、不抖（滚动顺滑）
- [ ] **细节**：圆角统一、统计数字等宽、各页（概览/历史/词典/风格/设置/引导）都磨砂、历史列表不再是不透明白底
- [ ] **窗口可用**：红绿灯按钮在、标题栏能拖动
- [ ] **胶囊一家人**：录音胶囊和窗口质感属于同一家族

### ASR 接线（本轮接上）
- [ ] **识别语言**：设置里选「English」后口述英文，确认 Qwen 识别更准（对比「自动」）
- [ ] **词典→识别**：把项目名/黑话加进词典并启用，**单击原文模式**下口述，确认模型直接认对（不靠润色）

### 音柱（频率驱动，已回退为原来的 9 根）
- [ ] **随内容变化**：说低音/「sss」/正常说话，9 根柱子跳出不同图案（不再全体一起涨落）
- [ ] **灵敏实时**：跟着说话实时增减，不再「起伏一点点就全落下」（rollingMax 衰减 ×0.995→×0.90）
- [ ] **静默回落**：停顿时回落到低静息线
- [ ] **手感调参**（如需）：`SpectrumAnalyzer` rollingMax 衰减 / attack(0.7) / decay(0.30)、`AudioVisualizer` 柱数/高度 真机调

### 胶囊收回 + 滑入滑出（本轮修）
- [ ] **正常结束收回**：单击 Command 结束后胶囊会下滑消失（之前一直挂着）
- [ ] **滑入/滑出动画**：开始从底部上滑淡入、结束下滑淡出

### 其他历史改动（更早几轮，未单独实测）
