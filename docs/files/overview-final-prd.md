# 概览页改版 — 最终实现规格(PRD)

> 交付方式:本 PRD = 实现规格;`overview-prototype.html` = 视觉目标(内联样式里有精确的颜色/间距/字号,直接照搬到 SwiftUI)。
> 技术栈:SwiftUI 原生 macOS,图表用系统 Swift Charts,不引第三方图表库。
> **本文档为最终版,取代此前所有零散笔记**(尤其:布局采用「固定宽度居中」,不再用自适应增减列)。

---

## 1. 布局模型(最高优先级)

### 1.1 横向:固定宽度居中,加宽只长两侧留白
当前问题:横向拉伸时中间组块被平行拉大。根因是封顶宽度没生效。正确写法是**两层 frame,顺序不能反**:
```swift
VStack { …内容… }
    .frame(maxWidth: 960)          // ① 先给内容封固定上限(可调,觉得宽就降到 880)
    .frame(maxWidth: .infinity)    // ② 再让外层撑满 → 居中,留白长在两侧
```
- 只写 ②、两行反了、或卡片自身还带 `maxWidth: .infinity`,都会变回"平行拉伸"。
- 内容宽度想小一点就调 ① 的值。

### 1.2 纵向:滚动,不压缩
- 全部包在 `ScrollView`,内容顶对齐。变矮 → 滚动看底部图表;变高 → 下方留白。
- 子组件高度全部固定/自然高度,不随窗口高度伸缩。

### 1.3 最小窗口尺寸
```swift
.frame(minWidth: 1040, minHeight: 700)
WindowGroup { RootView() }.windowResizability(.contentMinSize)
```

### 1.4 严禁
- ❌ `.scaleEffect` 做布局;❌ 用 `GeometryReader` 按比例算字号/间距/尺寸。字号、卡片高度全固定 point。

## 4. 数据统计 2×2

四块:**节省时间 / 口述字数 / 总口述时间 / 平均速度**(已去掉"口述次数")。
- 「节省时间」是 ROI 主指标,数字用紫色 `#B9AEFF` 描重,图标 `hourglass`。
- 数字排版:**大号数字 + 小号单位**。`2h51m` 中 `2`、`51` 为 27pt/600,`h`、`m` 为 15pt 次级灰。等宽数字 `.monospacedDigit()`。
- 图标:口述字数 `align-left`、总口述时间 `clock`、平均速度 `bolt`,均次级灰。

## 5. 成就区(统一暖色)

三块:**活跃天数 / 当前连续 / 最长连续**。整排统一暖色(琥珀 `#FFB454`),与上方紫色数据区形成"紫=数据 / 暖=成就"分区。
- 活跃天数:图标 `calendar` 暖色,副文案"本月共 N 天"。

## 6. 连续里程碑系统(多邻国式,放 `StatsConfig`)

```
milestones = [3, 7, 14, 30, 60, 100, 365]   // 天
tierColors = { 3:#FFB454, 7:#FF8A3D, 14:#FF6B35, 30:#FF4D4D,
               60:#E0479E, 100:#A99BFF, 365:#FFD24D }
```
- **火苗颜色** = 当前已达成的最高里程碑对应色(<3 天用起始琥珀)。达成新节点即升级换色。
- **进度条** 按"距下一站"填充:`pct = (streak - prev) / (next - prev)`,填充色用下一档颜色(暗示"正在升温")。
- **文案**:`还差 (next-streak) 天解锁 {next} 天里程碑`。
- **动效**:火苗呼吸 + 微光(参照 HTML 的 `flick` + `glow` keyframes)。达成里程碑时给一次性点亮/放大庆祝动效。遵守"减弱动态效果"时降级为静态。
- 可选:在某处展示里程碑总览(已达成亮起打勾、未解锁暗淡上锁),参照 HTML 窗口下方那条预览。

## 8. 活动热力图(配色=深色紫;交互=带 tooltip 贡献图)
- 数据:今天往前 365 天,**每天都生成,缺失补 0**(不要只画有数据的天)。
- 布局:7 行 `LazyHGrid`,周横向排;首列按真实星期补空占位对齐。
- 配色:空格 `#1C1C22`;5 档紫色 `opacity` 渐深(0.35 / 0.6 / 0.85 / 1.0)。阈值放 `StatsConfig`。
- **Tooltip**:悬停弹圆角深色气泡,白字 `5月7日 — 16,572`(日期 + 当天字数)。
- 图例:右下 `少 ▢▢▢▢▢ 多`。
- 超宽用 `ScrollView(.horizontal)`,默认贴右。

## 9. 24 小时分布(Swift Charts)
- 标题:`24 小时分布 · 高峰 21:00–22:00`(峰值取众数)。
- 固定 24 个小时桶(0–23)恒存在;`BarMark`,紫色;**峰值柱**用亮紫描重。
- X 轴只标 `0 / 6 / 12 / 18 / 23`。
- 全 0 时显示空状态文案,不画一条干巴巴的线。

## 10. 趣味文案
- 完整:`你已累计口述约 N 字 · 少敲约 M 次键盘 · 节省时间够看 K 部电影`。
- **低数值兜底**:不够"1 部电影"换更小比喻(如"够泡杯咖啡");字数极少时整句降级或隐藏,避免"少敲约 39 次键盘"这种尴尬。换算常量放 `StatsConfig`。

---

## 11. 指标计算口径(务必按此,修正现有失真)
- **总口述时间** = Σ 每次实际录音秒数(松手即停,不含停顿/处理)。
- **平均速度** = 总字数 ÷ (总口述时间/60)。⚠️ 分母必须是**纯录音时长**,当前疑似用了含停顿的总时长导致严重偏低(58 vs 正常 ≥150 字/分)。
- **节省时间** = `max(0, 总字数/baselineTypingCPM - 总口述时间/60)` 分钟。`baselineTypingCPM` 默认 40,**设置页可改**;填了时薪可附带金额估算。

---

## 12. 数据存储架构
- **音频永不落盘**;AppleSpeech 写到 temp 的 wav,在成功/失败/取消所有路径都 `defer` 删除。
- 文本+时长**从 JSON 迁到本地 SQLite**(JSON 做不了按日期范围/分组聚合,且有并发与损坏风险)。选型:最低 macOS 14 用 **SwiftData**(原生、`@Query` 直连);需老系统/强 SQL 用 **GRDB**。文件放 `~/Library/Application Support/<bundleID>/`。
- **不上云端数据库**;提供 JSON/CSV 导出 + 清空历史。云同步留作未来 iCloud opt-in。
- 隐私开关:`storeTranscriptText`(默认 true,关掉只存元数据)。
- 会话表字段:`id, startedAt, duration, charCount, wordCount, language, targetAppBundleID/Name, transcript?, editedCharCount?, sttBackend`。

---

## 13. 配置集中
所有阈值/换算/颜色/尺寸常量集中放 `Theme` 与 `StatsConfig`,不散在视图里(含里程碑节点与色阶、热力图分桶阈值、打字基准速度、趣味换算)。

---

## 14. 空 / 低数据状态
- 全空:统计区显示引导卡「开始你的第一次口述,数据会出现在这里」,不渲染空热力图/空柱图。
- 低数据:热力图照常铺满,柱图正常,趣味文案走兜底。所有聚合防除零。

---

## 15. 验收标准
1. 窗口由 1040 拖宽:中间内容宽度不变,只两侧留白变大;卡片不被拉伸。
2. 窗口拖矮:底部图表滚动可见,内容不压扁;拖高:下方留白。无法小于最小尺寸。
3. 全代码无 `.scaleEffect`、无按比例算尺寸的 `GeometryReader`。
4. 主内容区实色深底,无磨砂透背景。
5. 顶部 = 个性化 + 2×2 数据统计并排等高;数据统计无重复;数字"大号+小号单位"排版。
6. 成就三卡统一暖色;火苗按里程碑换色 + 进度 + 动效;设置齿轮在左下角可进设置页。
7. 热力图三种数据量都铺满正确网格,有图例与「日期 — 数值」tooltip。
8. 24 小时分布始终 24 根柱(空有空状态)+ 峰值标注与高亮柱。
9. 平均速度分母为纯录音时长,数值落在合理区间;节省时间随 `baselineTypingCPM` 联动。
10. 数据由 JSON 平滑迁移到 SQLite,不丢旧数据;temp wav 在所有路径删除。
